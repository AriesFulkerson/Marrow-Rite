How a 1v1 works

  1. The host taps Enter the Rite, then 1v1, picks a deck and taps Create match.
  2. The friend joins the host's address, taps 1v1, types the four-letter code and taps Join.
  3. The host keeps the app open while you play. The back button returns here.
